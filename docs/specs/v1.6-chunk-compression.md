# Chunk Compression to Prevent Duplicate Findings

> Release: **v1.6** · Label: `enhancement`

## Summary

For chunked reviews, compress findings from previous chunks into a summary and include it in the next LLM call's prompt. Prevents duplicate findings across chunks.

**Inspired by:** Alibaba open-code-review's `compression.go` conversation compression module.

## Why

When a PR requires multiple LLM calls (chunks), each chunk has no awareness of prior findings. This leads to duplicate findings across chunks and wasted tokens.

## Design

- After each chunk's findings are returned, build a compact summary (category + file + one-line description)
- Inject the summary into the next chunk's prompt as "already-found findings — do not duplicate"
- Keep the summary under a token budget

## Files

- `lib/prompt-builder.js` — accept prior-findings summary
- `lib/chunk-diffs.js` — pass findings between chunk calls
