# Semantic File Bundling for Chunked Reviews

> Release: **v1.6** · Label: `enhancement`

## Summary

When chunking diffs for multi-call reviews, group files by semantic relationship (import graph, test+implementation, shared directory) instead of only by token budget.

**Inspired by:** Alibaba open-code-review's `grouping.go` smart bundling module.

## Why

Current `chunk-diffs.js` splits files by token budget without considering relationships. A service file and its test end up in different chunks with no cross-file context. The LLM misses issues that span related files.

## Design

- Use `import-tracer.js` to build a dependency graph of changed files
- Group files that import each other into the same chunk (within token budget)
- Group test files with their implementation files
- Fall back to token-budget-only chunking when relationships don't fit

## Files

- `lib/chunk-diffs.js` — add relationship-aware grouping
- `lib/import-tracer.js` — expose graph for chunking use
